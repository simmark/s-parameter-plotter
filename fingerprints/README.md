# Fingerabdruck-Pakete

Hier können Vorlagenpakete des S-Parameter Analyzers liegen.

- **Erzeugen:** In der App Zahnrad → „Vorlagen & Einstellungen" → „Paket exportieren" (Desktop: Knopf „Vorlagen").
- **Veröffentlichen:** Die JSON-Datei hier ablegen. Als `default.json` wird sie über „Standardpaket laden" geladen.
- **Laden:** Im gleichen Dialog die Adresse (github.com/…/blob/… oder raw.githubusercontent.com/…) einfügen oder die Datei wählen.

Ein Paket enthält gelernte Fingerabdrücke (Portzuordnung, Abschlüsse, Kurvenwahl) und die Kurvenwahl je Bauteiltyp. Beim Laden wird jede Vorlage geprüft; Ungültiges wird übersprungen.
